# 亗NEXA亗

نسخة Front-end أولية جاهزة للنشر على Vercel أو Netlify أو GitHub Pages.

## الملفات
- index.html
- style.css
- app.js
- vercel.json
- netlify.toml
- .github/workflows/deploy.yml

## Vercel
ارفع الملفات إلى GitHub، ثم اختر Import Project في Vercel، واختر المستودع واضغط Deploy.

## GitHub Pages
ارفع المشروع إلى فرع main. الـ workflow الموجود في `.github/workflows/deploy.yml` ينشر الموقع تلقائيًا عبر Pages.

## مهم
هذه النسخة واجهة تجريبية. الحسابات، الدردشة بين مستخدمين حقيقيين، رفع الصور والفيديو، عداد المتصلين الحقيقي، المزامنة وحفظ مستوى الفيديو تحتاج Backend وقاعدة بيانات وخدمة تخزين.
